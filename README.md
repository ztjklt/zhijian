## 一张纸，可以变成什么？

《纸间》是一款正在开发的 2D 侧视手绘造物沙盒。你控制一个火柴人，在课本与墨线构成的世界里移动、绘画、搭建和交手。

画一座桥，试着走过去；画一把剑，决定握在哪里；画出一个奇怪的轮廓，看它落下、倾倒，又和别的东西碰撞。这里的线条不仅是装饰，也会成为可以使用、保存和再次创造的东西。

> **画下想法 → 确认造物 → 交给物理 → 继续创造。**

| 体验 | 在游戏里做什么 |
| :--- | :--- |
| ✎ 多笔造物 | 反复补画，亲手确认，让完整笔迹进入世界。 |
| ▱ 物理搭建 | 让建筑与自由造物下落、旋转、碰撞和堆叠。 |
| ⚔ 手绘武器 | 在真实笔迹上选握点，挥动自己画出的武器。 |
| ◇ 自动塑形 | 将粗略轮廓规整为几何部件，目前包含 44 种轮廓。 |
| ▤ 图纸收藏 | 保存作品，分类收藏，再次放置建筑或装备武器。 |
| ↟ 纸上探索 | 二连跳、攀墙、穿过平台，走进课本文字与中世纪山野。 |

## 正在把想象变成游戏

**当前阶段：本地持续开发中。** 当前本地核心为 Godot **v0.55 / r22 候选**；这里集中展示游戏概念、美术与阶段性实机内容。候选版本没有自动替换已经部署的公网版本。

| 模块 | 当前进展 |
| :--- | :--- |
| 核心造物 | 已有本机实现与专项验证：多笔绘画、真实轮廓碰撞、动态搭建、握点、图纸与安全落点。 |
| 移动与本机战斗 | 已有二连跳、攀墙、平台下穿、四式近战、短弓与交击；剑、锤、弓、长枪、火枪五类武器已接入本地候选。 |
| 地图 | 已有课本探索样段和中世纪山野地图，内容与场景持续迭代。 |
| 双人联机 | 已有 Railway 公网 WSS 双客户端验证，以及服务重启后的世界与作者身份恢复验证。 |
| 当前候选新增 | 联机移动预测、画稿预览、保存请求、结构连接、武器试打、双人共建、新手首件作品闭环、个人图纸恢复、持物姿态与 G 拿起／携带／放下。 |
| 待继续验收 | 不同网络的两台设备实玩、延迟与拥塞手感、移动端实机及发布包；本地 r22 尚未重新部署公网。 |

公网最新已发布基线为 2026-10-25 的 r7／协议6；当前源码候选为 r22／协议11，两者不能混用。历史验收记录见 [ZSCB/docs](ZSCB/docs)。同一台电脑上的两个公网客户端与异地两台设备实玩属于不同验证范围，后者仍待完成。

### 基本操作

| 输入 | 操作 |
| :--- | :--- |
| A / D · W / 空格 | 移动与跳跃；可二连跳、贴墙攀爬。 |
| 1 / 2 / 3 | 自由造物 / 建筑 / 武器；再次按当前数字键推进确认。 |
| 4 / 5 / 6 | 移动或拆除 / 自动塑形 / 图纸收藏。 |
| 鼠标左键 | 绘画、选握点、放置或编辑作品。 |
| R / Q | 攻击 / 切换试用短弓与近战武器。 |

武器类型轮盘与五类武器已经接入本地 v0.55/r22 候选；公网网页和固定分发包仍按各自发布记录执行。以上操作介绍不代表所有目标功能均已交付。
