# 纸间

在纸上画路、搭桥、造物，和画家阿靛、牧师、战神及冒险者砾舟一起探索。

**当前桌面试玩版** `bfe84bc10c6435e2`

## 拉取并试玩

安装 [Godot 4.6.3](https://github.com/godotengine/godot-builds/releases/tag/4.6.3-stable)。第一次下载，运行：

```sh
git clone --depth 1 --branch main https://github.com/ztjklt/zhijian.git
```

在 Godot 导入 [ZSCB/project.godot](ZSCB/project.godot)，按 F5。在 macOS 上也可双击 [打开最新版体验.command](ZSCB/打开最新版体验.command)。

进入封面后，选「试玩世界 → 三道新岸」直接上手，或从「队伍与世界存档」新建队伍。单人试玩可以直接开始。使用自己的模型时，见[模型连接说明](SOURCE_SYNC.md#ai-角色)。

已经下载过仓库的玩家，在仓库目录运行 `git pull --ff-only` 即可更新。
