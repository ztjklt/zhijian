# 动作参考

先定连接和受力。部件的枢轴应在外观相连的区域内，画出能够包住关节的厚度。轮廓本身有一小片相交区，转动时才不依赖一条恰好相碰的边。把力传给动作真正使用的部件，节链越长越要逐节检查。下列方法由当轮物种取用。

## 落脚和步相

| 形体选择 | 观察重心、支撑和留白 |
| --- | --- |
| 双足、类人、略高于人的怪物 | 从承重脚往上找胯、胸、头的线。大肩或前伸的大头可配略后伸的背、弯膝或尾。近脚踩稳时，另一只脚在地纸上方留出一段空隙。手臂可相反摆动，分成上臂与掌时，肘部保留转动的接面。 |
| 四足 | 肩和髋是两个主要支点。鹿原画中瘦踝靠前、后脚的间隔才能分辨，马原画的膝节借折角交代方向。肢根埋进躯干，腿从两个不同位置伸出。选对侧或对角的相位，取决于它让人先读出缓步、轻跑还是短促支撑。 |
| 多足、偏重或不对称 | 先选在一帧里真正受力的一组脚，再按相反节奏分出另一组。远侧可借少量同色影来交代。大钳、背囊或单侧斜角会偏重，可配更宽的支撑脚、低身躯或另一侧尾梢。无须对称补一只外形相同的肢体。 |

模仿承重时保留一只或一组可读的支撑肢。用实际步相核对休息、前摆、后摆三帧，远近两脚轮流露出。若脚端在两个相位都画进坡或躯干，改足端长度、关节位置或相位。当运行只提供整体摆动时，可以用固定的下节和清楚的膝折表现关节，避免把同一大幅摆动叠在两节。

## 翼、尾和起落

蝠原画的上拍、伸翼、下拍和落地收翼是一套可见轮廓。宽翼根先紧贴肩，翼骨或羽束朝梢端收，薄膜只填翼面，不越过折线。先试最高和最低两帧，特征耳或吻不能一直被翼根吞没。双翼若承担升力，强拍要读成同一个节拍，远翼可在轮廓上稍偏后；若用途是遮护或威吓，动作可偏在一侧。

旧叶角巡兽的两翼有些翼相会互盖成短背甲。先从远翼露一个向尾的浅色梢，再让近翼有不同的外缘折向；轮廓露头、露尾方向各留一处纸白。胸背上相交的两件可由深度和淡彩分前后，关节仍留在身体里面。改稿时可只改那一翼的点列、层次或明暗，从首稿相同翼相复看。

若运行支持 `fly` 和 `flap`，至少给两件实际相接的 `flap` 部件。选择适合现场的巡飞高度，先找头顶净空和体力可及的落点。借屈腿、展开翼根表达起跳，用翼下拍和离地描述起飞。靠近地表时足端向下，收翼后由脚接住重量。大翼先试较收敛的摆幅并在上下极相看胸部与翼面是否互相遮住。调 `rate`、`amplitude`、`phase` 只用工具提供的值，两片飞行翼的节拍要一起读。地面单位有翼时，仍以脚和地面活动表现负重，宽翼可帮助守势或平衡。

纸龙原画的宽尾根连脊，尾节逐段变窄。把最醒目的钩、分叉或哨尖放在能在相机下独立露出的末节。摆动时根带梢，末节少量滞后。长尾下压时为坡面和后脚留空，普通步态的支撑由脚给出。

## 动作与目标

取食先辨头的方向与可接触的目标。啃树时让吻部靠近树皮，食草时低口够到近地草茎。`jaw` 枢轴藏在眼后或头体里，下颚缘开合时还能看出头。追捕者把方向和抓、咬或冲撞的接触面画在行动负责的一端。护食用身体挡住食点、突出转向来表示防守。趋避、进食、威吓、护食与猎捕分别按现场事实和工具判断。动作预备、接触与回收各留一个清楚的姿势。

## 在真实相位留出头脸与接触点

- **巡飞到收翼。** 读原件的父子、转点与前后层，按同一机位检查巡飞的两个相位、下降和着地收翼。每相先找朝向用的吻端或冠根，再从肩下分别找近远翼末端。若近翼外片在收翼时横过脸，先让这一片外梢折向尾侧，留肩上的翼根、连接面与原摆相。另一翼可露一小片较浅的尖端。小窗至少能分别指出吻端和翼尖，较大的纸白留在冠缘与外片之间。写回前用原地表核对着地的一脚和收翼剪影。
- **低头近果。** 同一地面看循果、将触与果消三个真实相位。将触时用实际果心和原嘴缘顶点找挡住果边的一件。例如浅远颊、远前掌或前胸可能在最低头相盖住它。若口缘已经够到果，先只收挡果部件靠果的投影，或给吻尖一片能从颊边辨清的浅面。保持口缘顶点、父枢轴和承担重量的最低点。先以默认镜头能认出一段连续红弧为目标，低头前果块能单认，碰到后再按场内果的计数核实。

优先改所见问题对应的一件。把原笔和改笔放在同一真实相位比较，其他已读得清的部件照原件。翅梢离开脸、嘴靠近果与真实落脚，各按本轮引擎回执判断。
