## 可复现验证入口

在仓库根目录执行：

```sh
python3 ZSCB/tests/run_checks.py --godot /path/to/godot --logs /tmp/zhijian-checks
```

默认依次执行完整原生行为、Python（含真实本机网关／Godot传输）、匹配Web适配后的完整当前行为测试；任一失败则整体非零。当前带保存队列的Web会话明确排除online_save_legacy_test.gd，该测试要求无队列的旧会话；保留原4项断言，在实际r7旧包准备副本单独通过4／0，不以当前会话冒充旧夹具。`--stages native python web`可显式选择。运行时按显式路径、GODOT_BIN、PATH及已安装macOS位置查找。所有游戏测试在副本、随机个人目录和临时世界目录运行，不用真实资料。日志保留至指定目录；未指定则临时清理。

Web阶段实际准备完整客户端并用原生Godot运行其GDScript，不等于浏览器WASM验收。另行导出：

```sh
python3 ZSCB/web/build_web.py --source ZSCB --output /tmp/zhijian-r22-web
```

需要匹配4.6.3导出模板。`.github/workflows/checks.yml`固定Linux Godot4.6.3下载校验和，只离线验证、上传测试日志，无部署步骤。历史r7／r13私有固定包未收录时明确skip；可用PAPER_LEGACY_ROOT指定包含旧dist的目录。当前源码测试不跳过，不宣称干净检出已验证所有旧固定包。本机额外指定已有历史包目录后，6项Python Web准备／保护测试全部通过，包含协议6／r7和协议10／r13。
