# 简洁纸面 UI · 本地试玩

2026-10-25，用户认可两张 GPT 概念图后明确要求接入试玩。核心 Godot 项目原位更新；封面图层与三个原入口保留。

## 已接入

- 暖白纸面、细边框和统一墨线图标，青绿强调当前工具；GPT 生成为文字让位的低噪纸纹，实际接入图纸底层。
- 左上生命／墨水，右上地图／作品；地图导航默认收起。桌面底部工具整合为造物、武器、移动、塑形、图纸，自由和建筑置于造物子选项，1–6 原快捷键与同键确认保持。
- 图纸居中弹窗：桌面卡片／详情分栏，窄屏纵向滚动；每页六张、真实图形预览、搜索分类、收藏／改名／更多、六格绑定、分页和复用。主操作与分页置于滚动区外，世界背景轻遮罩，不暂停物理。
- 禁用按钮仍拦截落笔，控件间空白允许绘画；图纸名称在选中 ID 改变时更新，避免将旧草拟名称写到另一作品。
- 保留高 DPI UI 缩放；短横屏／竖屏在顶部状态下方排列工具，为下方移动与攻击触控留空间。

## 试玩

根目录 `打开新UI试玩.command` 会导入当前核心资源并打开中世纪本地场景，窗口标题随当前版本显示为“纸间 · v0.37 · 武器音色与死亡叫声 · 最新 UI 整合版”。它与最新强化命中、逐步破损和五种武器使用同一份代码。现有其他试玩进程未停止。正常从开屏进入各地图也使用新 UI。

本轮没有发布网页、更新云端权威服务或改动固定分发包；当前整合主线协议6与公网协议2边界保持。
