# 纸间：第六阶段「第一件作品」

SPEC v0.46，本地r13，协议仍为10。第六轮只增加单人学习目标，联机规则与r12兼容；公网仍r7／协议6，未发布。

首次单人进入时显示可跳过的四步目标：画一个矮而宽的踏板→明确确认生成→站上它或亲手搬动→实际保存成功。玩家仍画自己的完整笔迹，可以多笔补画；不注入预制件，不强制改形状，不自动生成／保存，不移动人物、不清空作品或其他工具草稿。1自由、2建筑、5塑形的真实成功都可计入；从作品菜单可主动重开。

只有脚下真实支撑是本轮部件并持续0.3秒，或4工具实际拖动至少0.25米，才进入保存。自动避障、重力下落、等待、靠近旧物件都不计。目标按已有稳定structure_id追踪，物理落点和标记一致。未完成时目标被删、破坏、撤销，或切图／读取旧世界，会回到绘制目标，保留原作品。

保存使用原SaveStore实际写入结果，失败留在原步并可重试。完成或跳过只写个人引导偏好，不把课程状态放进世界、物件或图纸；已跳过旧guide.seen的玩家不再自动被教学。中世纪原入口曾主动隐藏旧引导，新课程在此前捕获首次偏好，因此默认地图也能使用。

桌面复用侧边详细卡片，窄屏复用原工具栏状态行及短按钮；短按钮标实际工具数字，避免把课程步数误当按键。没有新增挡住摇杆的模态窗。引导不暂停世界、不屏蔽自由绘画或移动，不改已有NPC、生命和墨水。原PaperOnboarding接口保留。联网客户端不启动该单人课程，headless权威不创建课程实例。
