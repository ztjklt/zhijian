# 封面与游戏 UI 闭环验收 · 2026-10-24

本轮按照用户“把之前做好的封面放上去，开始UI都能点击，并形成完整闭环”的要求完成接入。不是重新生成封面：八张 PNG 与 `docs/art-direction/cover-v10/assets/` 逐字节一致，保留 `layout.json`、`manifest.json` 和原提示词档案。

## 实际入口与行为

- F5／运行项目默认 `scenes/title_menu.tscn`，本地打开工程和运行脚本沿用这一入口。
- 封面“单人练习”进入现有两张地图及旧作品继续入口；“多人对战”进入真实双人大厅；“设置”即时改变总音量、4× 2D抗锯齿、世界轻锐化，独立持久保存在 `user://preferences.cfg`。
- 选图／大厅都有返回封面和Esc返回。作品菜单增加返回选图、保留进度返回封面、保存并返回封面。保存失败留在游戏并显示原因。
- 返回保留本机休眠会话内的草稿、装备与地图搭建，继续游玩恢复同一对象。正常作品保存仍仅保存已生成作品、图纸和装备；关闭进程后未生成的草稿不持久保存。
- 休眠世界的 CanvasLayer 隐藏；设置改变或返回封面不能重新显示其锐化层，继续时重新应用设备偏好。
