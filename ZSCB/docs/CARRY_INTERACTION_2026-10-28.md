# 拿起、放下与携物交互 · 2026-10-28

本轮完成部件的拿起、携带和放下闭环。4 工具先选中部件，再按 G；拿起后部件跟随角色前方位置，冻结并暂时关闭碰撞，角色仍可走、跳、画和进入其他非破坏 UI。再次按 G 会把部件放到角色前方，先通过真实轮廓的安全落点检查；落点被占用时保留携带状态并提示。

权限沿用现有规则：单机可搬动本机作品；联机只能搬动自己的作品或作者已开放协作的作品。已连接结构必须先解除，不能用携带绕过连接约束。拆除、图纸、攻击和现有鼠标拖拽继续保留。

联机新增协议11的 `carry` 命令。服务器保存每个玩家的 carried id、原碰撞状态和短期锁，在物理 tick 中根据服务器角色位置更新物件；放下再次检查范围、几何安全落点和当前权限，客户端只显示结果。错误对象、旧版本、无权限和错误放下不会清除携带。死亡、断线、房间结束自动恢复碰撞并释放锁，物件不会被删除。

验证记录：本地携物专项 6／0；网络权威专项 8／0；完整隔离回归和匹配 Web 专项在本轮冻结包验证后补入最终状态。所有测试使用临时工程、随机私有用户目录和私有本机房间，未触碰真实作品、Railway 或公网 r7。
