# 指尖 · 双人对战 r2 验收

2026-10-25（上海时区）。**已部署 Railway，当前为20261025-r2 / 对战协议2。** 同一电脑的两个真实客户端通过公网WSS验证；不同网络、两台物理设备的人类实玩仍未验收。

## 现在怎样联机

采用「云服务器＋房间码」，由现有 Railway「纸间」服务托管，不使用玩家电脑托管或公共随机匹配。

1. 两人使用同一个r2包。macOS双击 `打开指尖双人对战版.command`；其他系统用Godot4.6.3导入 `project.godot`，从封面进入「多人对战」。
2. 两边点「使用纸间云服务器」。地址已预置为 `wss://paper-server-production-4b68.up.railway.app/ws`。
3. 一人创建房间，用「复制房间邀请」把8位房间码交给朋友；朋友输入房间码加入。每房最多2人。
4. 创建者离开会保存并结束房间；客人退出后房间继续。下次由创建者重新打开自己的云端作品，并发送新房间码。

固定源码为根目录 `dist/指尖双人对战版-20261025-r2/`。分享包为 `ZSCB/releases/指尖双人对战版-20261025-r2.zip`，**需Godot4.6.3，不是独立Windows exe或浏览器版**。旧2026-10-24包保留历史，不能继续连接当前协议2服务。

## 复审与测试发现

独立只读审查发现2项Important（握点未取消权威拉弓、共享箭矢裁决effects累积），均先复现再修复，无Critical。首轮全量69/74中的5项旧地图夹具已修正：地形3现合法、oak-1已退役、原空中/战斗目标位置被新山体占据、车夫冲击被村庄碰撞干扰；只调整夹具，不修改地图或放松命中/性能断言。

公网检查进一步发现装备竞态和木箱三角化精度错误，已形成装备回归及真实渲染回归。公网测试走位先测实际RTT，使用短时真实输入并等待权威状态，避免把零延迟假设混入验收；没有伪造位置或放松命中规则。

## 仍需实际设备验收

- 同一电脑两客户端通过真实公网，**不能代替不同网络两台物理设备的人类实玩**。
- 最近一轮生产地址应用ping中位约251.9ms、最大384.6ms；此前一轮中位282.8ms、最大611.3ms。不能称为真实公网100ms或主观无延迟。
- 当前本机角色采用权威位置插值，未新增移动预测。模拟100ms/限速通过不等于所有公网拥塞下都流畅。
- Windows独立exe、浏览器版和武器类型轮盘/持物模式没有在本次冒充交付。
