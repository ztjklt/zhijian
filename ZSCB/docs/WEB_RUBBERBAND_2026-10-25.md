# 纸间：移动回拉修复（2026-10-25）

用户实玩反馈：上一轮即时移动后稍流畅，但行走时仍突然向后退。本轮针对普通位置校正及短消息停顿恢复，采用固定r2／协议2兼容附加元数据，不部署主线协议5。

## 修改与依据

旧网页根据变化的ping估计历史位置；消息积压恢复后直接采用迟到的服务器位置。真实控制器／历史夹具在ping从600ms变为100ms时复现单帧后退0.417米；短状态间隔也会把显示位置直接回退。

权威状态新增可选 `input_ack`（既有输入序号）、`input_age`（服务器模拟时间）和 `movement_reset`（重生／安全重定位）。服务器仍只接受操作意图；没有信任客户端位置／时间戳，没有改变协议版本、碰撞、战斗规则或存档格式。旧客户端忽略新增字段。

网页记录输入对应的本机模拟时刻，按实际确认输入匹配历史；尚未确认的转向／跳跃不被旧状态覆盖。普通误差与短消息停顿恢复均限制为0.9米／秒（60Hz约0.015米／物理帧），不再因普通位置差超3米或短停顿而瞬移。确认阻挡后限制继续超前，直到位置收敛；输入超时仍停止预测，不能无限在本机跑动。死亡、重生、世界切换及服务器明确重定位仍立即服从权威。跳跃按住／次数、绘画镜头稳定、立即上传输入保留。

这不是确定性输入重演，也没有降低实际互联网往返时间。动态物件碰撞、远端玩家与战斗确认仍受线路影响；长中断仍会停止预测或重连。
