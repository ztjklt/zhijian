# 2026-10-25 底栏轻量化

用户要求移除底栏大框、采用半透明界面并减少对游玩画面的遮挡。范围仅 `scripts/toolbar.gd`，未修改全局纸张主题、背包、地图或操作流程。

## 实现

- 底栏外层改用无绘制的 `StyleBoxEmpty`，移除整块纸纹、边框与阴影。
- 每个实际按钮使用独立小底色；普通底色 68%、主操作 78%、禁用态 62%，悬停／按下 84%／82%。字色与整个控件始终保持 100% alpha，避免把文字一起淡化。主按钮使用更深墨青色，在现有纸色上按 alpha 合成计算与字体约有5.15:1对比，实际启用态已截图检查。
- 两行工具按实际内容收缩；状态提示字号12、无背板，保留浅色文字阴影。桌面底部居中、留14逻辑像素，窄屏仍位于顶部工具下，不占触控摇杆区域。
- 外层容器和状态文字不拦截 GUI 输入；点击实际按钮（包含禁用按钮区域）仍不落墨。触屏按钮沿用同一物理矩形。
- 保持自由／建筑／武器／移动／塑形、候选确认、握点返回与确认、撤销／重做／拆除的真实回调。

## 验证记录

先写独立 `bottom_hud_test.gd`，在原实现上实际得到 258 项检查、69 项预期失败；失败集中在旧外框、空白区域拦截、实色按钮和118逻辑像素的桌面高度。无脚本或解析错误。随后增加真实鼠标从状态文字处落笔检查。

最终隔离验证全部成功，真实存档与用户运行窗口未改动：

首轮 Metal 快照碰到并行地形正在等待的 `is_ground_animal()` 接口，作为未通过记录丢弃；接口就绪后重新拍摄并确认日志干净。读图另外发现首次进入时 Label 换行曾让无形外层暂时保留530逻辑像素高度；已用实际最小高度变化及布局后收紧修正，并增加首入与截图高度检查，最终所有桌面模式80、紧凑模式68逻辑像素。最后一轮加入真实草稿／选中握点，检查主操作启用态字色。
