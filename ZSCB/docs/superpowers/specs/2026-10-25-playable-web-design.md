# 指尖：直接可玩的公网网页

用户要求“直接给我一个可以玩的公网网址”，授权完成浏览器适配与部署；无需再次选择方案或审批设计。以当前已上线的协议2/r2固定源码为基础，保留封面、单人、绘画和双人房间。

选择Godot4.6.3 Web导出，Compatibility/WebGL2、单线程模板；用独立Railway静态网页服务托管导出文件，客户端继续连接现有WSS权威服务器。比重写游戏更能保持现有物理／玩法；比给权威网关追加网页托管更少影响正在运行的房间。开发目录和r2固定源码不覆盖，Web适配在单独副本中完成。

必须内置可分发的开源中文字体、正确的wasm MIME及压缩，提供可见加载进度与失败重试。先验证本机浏览器封面／单人移动与绘画、再验证公网浏览器创建房间及第二真实客户端加入。网页返回200不构成可玩证据。不得把旧桌面包、控制台或healthz当作最终网址。浏览器存档属于该网站的本机资料，不迁移原生客户端私有凭据。

不更改现有协议、权威服、持久卷或玩法。手机实际性能与不同网络两物理设备不因浏览器测试自动通过。
