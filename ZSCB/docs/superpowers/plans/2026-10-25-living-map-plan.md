# 中世纪流畅与生态修订

用户已明确执行方向：少树、多行走人物／动物／飞行生物，两侧山地与起伏道路，底部半透明且去大框。继续当前 Godot 工程及已授权的分工实施，不另建项目或远端部署。

1. 根代理记录修改前1440×900六区域实渲染性能；完成当前人物／城堡表现的视野筛选和同材质复用。表现裁剪不能影响实际位置、碰撞、伤害和回到视野后的动画。
2. 地图代理调整稀疏构图、巡逻与两端可走山地，维持实体上限。内容／地形v3分别迁移，保留伤亡、破损、玩家和造物相对旧地面的高度；根代理接入主入口及保存校验。
3. 美术代理分别生成兔、鹿和蝙蝠怪透明墨线序列图，接入实际巡逻／飞行／受击／死亡，复用已有马与龙；人继续使用原火柴人骨骼。根代理与地图代理约定新类型和稳定ID。
4. UI代理仅调整底部控件：透明容器、小块半透明按钮和紧凑浮字；保持四尺寸布局、点击和绘画穿透。
5. 串行运行必要的隔离测试／真实Metal截图，覆盖人物与马车坡面、山路通行、保存迁移、动物互动、底栏操作及自动落点。用同一性能脚本复测六处，记录实际差值及负载限制；独立复核后另开当前本地游戏。

方案采用有限地图的整体重排与视野表现优化。仅删除树不能解决屏幕外骨骼／绘制开销；单纯增加生物会扩大现有开销。保持世界模拟，只减少不可见表现与不变静态工作的方案符合既有物理和多人方向。
