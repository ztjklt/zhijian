# 磨坊试桥 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在中世纪地图增加可选的真实物理送货试桥，允许不同手绘结构解法，并完整保存、共享进度。

**Architecture:** 新建独立`mill_bridge_trial.gd`模块，挂在MedievalWorld下。两端试桥台只有玩家主动布置且位置安全时才创建；货车使用真实刚体、轮形碰撞和有界地面驱动力，不沿预定坐标移动。单人本机或联网权威推进事件，客户端只展示快照。事件有新地图碰撞与命令，因此开发候选升为协议7，公网r7及本地r8不变。

**Tech Stack:** Godot4.6.3 / GDScript / 既有WSS与存档。

**Spec:** `ZSCB/SPEC.md` v0.41的渐进改进授权；本轮细化为v0.42。

## Global Constraints

- 保留已有绘画、原笔迹、伤害、墨水、数字键、图纸与作品。
- 旧作品缺少事件字段时为未布置状态；不自动往旧作品里插入碰撞体。
- 布置与重试只处理事件所有的试桥台／货车，不删除、修复或重置玩家搭建。
- 单人／联机共用模块；联网位置、接触和完成由服务器决定。
- 临时副本与用户目录测试；不自动部署、不覆盖r7/r8冻结包。

## Design and alternatives

采用磨坊渡口上方的可选试桥台，左中心129.5米、右中心137.5米、台面高5.2米，各宽2.2米，中间空缺5.8米。玩家可画整块桥板，也可搭中间支撑再接两块板。考虑过拆掉现有河桥及新增马车剧情：前者会改变旧作品通行，后者现有马车贴地控制不能证明桥的承重，因此本阶段使用独立真实刚体小货车。

事件阶段为idle→ready→running→failed或delivered。布置时检查两端与现有物体／玩家不重叠；起点被挡住时拒绝投放，不改变当前阶段或扣墨。货车只有实际接触时获得水平驱动力；无桥会落下并失败。必须抵达右台、实际接触且速度稳定持续0.5秒才完成；经过目标上方、玩家独自跨过去、浮空或草稿都不能完成。重试不消耗墨水、不发放资源或图纸，保留完成记录。

现有地图面板增加入口与就近提示、布置／投放／重试按钮；桌面和窄屏可用，触控经现有按钮归属处理。单人可从入口前往事件，联机沿地图实际走过去。世界与好友不暂停。

## Review Focus

- 不通过直接改货车坐标模拟通关，不把装饰或草稿当支撑。
- 旧存档、失败重试、地图返回和服务器恢复不清理玩家作品。
- 不能从客户端提交完成、货车位置或未验证事件状态；重复请求不重开事件。
- 缺失／非法事件存档字段必须分别兼容／原子拒绝。
- 触控事件按钮不落墨，窄屏不挡住主工具与移动区。
