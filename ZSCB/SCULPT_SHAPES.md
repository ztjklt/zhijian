# 自动塑形库：44 种轮廓

5 开始绘画，可松手、停顿、继续画多笔，再按 5 确认；各笔合为一个部件。成功后回到之前的工具，4 可以移动组合，新部件自动收入图纸。

| 分类 | 形状 |
| --- | --- |
| 基础几何（6） | 圆、椭圆、矩形、正方形、三角形、直线 |
| 特殊四边形（5） | 菱形、平行四边形、梯形、直角梯形、风筝形 |
| 正多边形（7） | 正五、六、七、八、九、十、十二边形 |
| 星形（4） | 四角星、五角星、六角星、八角星 |
| 组合部件（6） | 十字形、T形、L形、人字形、箭头、双向箭头 |
| 常见轮廓（3） | 心形、盾形、房屋轮廓 |
| 曲边实体（7） | 胶囊形、圆角矩形、半圆、四分之一圆、扇形、拱形、C形 |
| 开放轮廓（6） | 直角折线、V形折线、锯齿折线、半圆弧、四分之一圆弧、四分之三圆弧 |

闭合轮廓形成实心部件，凹形保留开口；开放轮廓是有厚度的杆件。圆弧与半圆实体是不同类型，需要半圆实体时应补上直径底边。

系统比较相近的几何和模板轮廓，支持旋转、多笔拼接以及可识别的长宽变化；正多边形和星形保持规则比例。形状很草或意图模糊时仍可能识别为相近类型，也可能保留草稿请继续补画。自由轮廓可使用 1／2 原笔迹生成。

后续扩充在 `scripts/sculpt_library.gd` 中添加轮廓、名称和可变形规则，并通过 `tests/sculpt_library_test.gd` 验证真实识别、碰撞、图纸及存档。不能仅登记名称而没有可生成的轮廓。
