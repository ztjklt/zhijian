当前统一游戏规范见 [SPEC.md](SPEC.md)，开始开发前同时阅读 [AGENTS.md](AGENTS.md)。规范包含多人沙盒和 Railway 部署目标；当前已有本地验证的双人实现，云端上线状态以专门验收记录为准。

角色进入游戏即可移动，绘画、选握点、搭建和编辑期间均保持实时行动。可以连续多轮、多笔补画，松手或长时间等待都不会自动生成。

数字 1–5 与顶部工具按钮使用同一流程：1 第一工具、2 建筑、3 武器、4 移动／拆除、5 塑形；再次按当前数字键推进确认。6 / B 打开或关闭图纸，Shift+1–6 仍只取用／绑定图纸，不同时切换工具。内部模式编号保持兼容，不能直接用数字键值当作内部编号。界面与引导以数字键为准。

素材识别出现候选后，再按 1 确认当前候选。打开图纸或失焦会把已画够长度但未松手的一笔保留为草稿，不生成物体；Esc 仍主动取消当前未完成笔画。武器类型轮盘已经接入；装备后的剑、锤、长枪使用不同待机持握姿态，切换空手或绘画会恢复基础动画。按 4 选中可编辑部件后按 G 拿起，角色移动时携带，再按 G 放下；联机由服务器验证权限和安全落点。

各模式独立保留草稿，切换时收尾有效笔迹，草稿在纸面／空中一直可见。单件作品允许最多 128 笔；达到采样密度上限后压缩密度继续采样，不能截掉后半段。生成失败保留画稿。此处是资源保护上限，不要求玩家一次按住画完整件作品。

武器握持点必须点在真实线段上；接近线条的点击会吸附，笔画之间空白不能作为握点。点击后只出现选点标记，允许改选，最后按 3 或「确认装备」才替换原武器。多笔使用共同变换，保留朝向、比例和彼此位置；尺寸在合理范围内等比归一化，握持点贴合角色手掌。支持现有形状驱动的近战、距离、伤害和冷却。

建筑默认按原轮廓生成动态刚体，确认后才下落。闭合轮廓形成实体，未闭合笔画是有厚度的杆件，凹口保持开放。平底、斜底和弯底的稳定、倾倒、滚动与堆叠由 Godot 物理计算。「轮廓」按钮保留平台、城墙、梯子、斜坡、塔楼和门洞等候选；需要自动几何规整时用 5。生成位置受阻时，整件平移到最近合法安全空位，再交给真实物理下落。原始确认位置保留12米范围，避让后的落点不再受该半径截断；几何无效、确实不存在合法落点、原始距离超限或容量已满时提示原因并保留草稿。

5 的塑形库已扩充为 44 种轮廓，包括基础几何、特殊四边形、正五至十二边形、星形、箭头、心形、房屋、拱形和开放圆弧等，完整清单见 [SCULPT_SHAPES.md](SCULPT_SHAPES.md)。尽量保留位置、大小和倾斜方向；难以识别的轮廓保留草稿供补画。开放圆弧保留为杆件，拱形和 C 形保留开口。成功生成后回到此前工具，独立部件可通过 4 移动组合，并可从图纸复用。

「练习场」仍可生成练习靶和墨弹设施，武器能打靶、建筑能挡弹并被破坏；练习状态不保存。多人互伤和云端房间使用独立联网入口，验证范围见联机验收记录。
