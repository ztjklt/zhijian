# 纸上城堡 · 持物、武器与墨水增补 SPEC（待审）

日期：2026-10-24  
基于：当前 `SPEC.md` v0.6，以及本次用户最新指令。  
状态：供用户过目；尚未合并为正式规范，本文不表示功能已经实现。

## 1. 本次已明确的要求

- 1 改为持物／使用模式，没有绘画。
- 3 仍可多轮多笔画武器；依次经过绘画、选择握点、选择类型、最终装备。
- 类型选项围绕鼠标排列；玩家明确指定物品用途。
- 剑、锤使用人物挥击动作；弓、枪有各自的使用方式。
- 制作完成的武器进入背包，能够重新取出使用。
- 加入墨水值：绘画、射箭和开枪都少量耗墨，消耗非常慢，优先保证创造的爽感。
- 地形中分布墨水池，玩家从背包拿出取墨器补充墨水；取墨有独立动作。
- 保留异地双人共享沙盒、互伤和优先 Railway 的方向。

以下具体数值、六种类型、背包组织和补墨细则是本稿建议，等待用户审阅。

## 2. 实现方式与当前基础

采用用户指定的“玩家选用途，笔迹做外观”。自动识别弓枪会猜错抽象图画，确认前额外填写文字又会增加步骤，因此本轮不引入这两条路线。

当前 Godot 核心已有多笔草稿、真实线段握点、手部挂载、图纸收藏、近战及近期加入的短弓／箭矢试打代码。它们尚未形成按手绘物品类型驱动的完整装备系统。新实现沿用这些基础和现有角色骨架，补上类型状态、物品背包、攻击动作、墨水及池子。最近加入的二连跳、下穿平台、44 种塑形与造物反馈继续保留。

本稿先定义本机完整玩法，再把同一套操作与资源规则接入权威服务器；本机通过不能声称异地联机已经完成。不增加敌人种类、付费素材、交易、耐久、装填或独立弹药背包。

## 3. 工具分工

遵循并行任务刚合入的正式 v0.6：数字 1–5 为主操作，F1–F5 保留对应兼容入口；用户本次说的 F3 流程同样由数字 3 推进。6／B 开关背包，Shift+1–6 仍用于快捷格。下文用数字键描述，两个入口必须调用同一逻辑。

| 快捷键 | 规则 |
| --- | --- |
| 1 持物 | 拿着当前装备，以鼠标瞄准，主操作键使用；拖动不产生线条。空手时不生成物品。 |
| 2 造物 | 保留原笔迹，绘制普通动态物体和建筑；再次 2 确认生成。原 1 的自由线条造物能力由此承接，不能只剩预设建筑。 |
| 3 手绘装备 | 多笔绘画 → 选握点 → 类型轮盘 → 确认入包并装备。 |
| 4 编辑 | 沿用选择、移动与拆除，以及多人作者权限。 |
| 5 塑形 | 沿用多笔确认和 44 种识别；成功后返回进入前工具。 |

装备完成后自动回到 1。切换到 2–5 时装备仍归玩家所有，但不能用正在画线的同一次鼠标输入触发攻击。各模式草稿独立保留，世界不暂停，WASD、跳跃和已有攀爬持续可用；文字输入保持原有输入隔离。

1 鼠标左键／触控“使用”统一使用物品，R 作为同一动作的兼容输入；弓按住蓄力、松开发射。右键取消当前操作；在 1 中不再额外触发另一套攻击。绘画模式中对应工具键和确认按钮推进阶段，右键／Esc 返回上一步或退出当前阶段，不把取消变成造物。旧 Q 临时切弓入口由背包装备替代，防止凭空出现第二套武器。

## 4. 3 的四次按键

1. **第一次 3：绘画。** 在纸面／空中画多笔，可松手、停顿、补画和移动。草稿保持世界坐标，不随人物飘走。
2. **第二次 3：选握点。** 冻结本件笔迹，点击线条选择握点；可改选，空白无效，多笔统一变换。尚未装备。
3. **第三次 3：选类型。** 只有有效握点才能打开轮盘。轮盘以打开时的鼠标位置为中心，靠近边缘时整体移入屏幕；草稿及握点继续可见。
4. **第四次 3：完成。** 玩家先点击一个类型，再按 3。校验成功后一次性创建背包物品、保存配方、替换手持装备、清除这件草稿，回 1 并播放成功反馈。没有选类型时停留并提示。

轮盘建议六项：**剑、锤、弓、枪、普通物件、取墨器**，六个方向排列。类型高亮展示用途和动作提示，不能在鼠标经过时直接提交。触控点击同一选项，再点确认按钮。

轮盘中 Esc／右键回握点，握点中返回绘画；退回绘画修改笔迹会清除旧握点与类型。切换工具、失焦或开背包取消蓄力／持续使用，保留这件草稿和已有效的阶段信息，恢复时重新按键确认，不能因按住的键自动完成。任何失败不清稿、不丢旧装备、不播放成功仪式。

满背包、无效尺寸、非法握点等在最终提交前拒绝；物品、配方与装备共同成功或全部保持原状。成功反馈沿用当前效果，武器为 `FORGED!`，普通物件／取墨器为 `CREATED!`，只在最终成功时触发。

## 5. 类型、攻击与人物动作

外形决定呈现，类型决定行为；不能画得越大就无限加伤害。攻击配置集中管理，存档及未来服务器从合法类型重新取配置，不信任外部传入的任意伤害数值。

| 类型 | 使用方式与人物动作 | 建议起始数值 |
| --- | --- | --- |
| 剑 | 面向瞄准方向，前挥、收回；命中期与挥动一致 | 伤害 22，冷却 0.45 秒 |
| 锤 | 抬起、向前重击、收回；比剑慢 | 伤害 36，冷却 0.9 秒 |
| 弓 | 双手持弓、后手拉弦，松手放箭；保持下肢移动 | 蓄力 0.25–1 秒，伤害 18–30，箭速 14–22 米／秒 |
| 枪 | 持枪瞄准、扣动、轻后坐；按住可按冷却连续射击 | 伤害 12，间隔 0.3 秒，弹速 45 米／秒 |
| 普通物件 | 手持任意外形，使用时短距离向前挥一下 | 伤害 8，冷却 0.65 秒 |
| 取墨器 | 靠近池子持续使用，执行专门取墨动作 | 不造成攻击伤害 |

这些是可调默认值。近战范围按最终统一缩放后的线条相对握点计算，并限制在 0.6–2.2 米；普通物件上限 1.2 米。弓不足最短蓄力就松开为取消，不发射、不耗墨；达到上限不自动射出。放箭后的最短间隔建议 0.45 秒。弓箭有轻微下坠，枪弹近似直线，均为有飞行时间的投射物。

握点仍是唯一需要玩家点击的节点。类型阶段显示自动朝向／发射方向预览，不增加“再选枪口”步骤。建议以握点指向最远笔迹点作为局部前向，等距时用固定顺序确定，整个图形共同旋转；发射点为该方向笔迹最前端外少量偏移。结构奇特时先保证预览与装备一致，后续才考虑可选的方向调整。

近战对每个目标独立检查实际遮挡，同次挥击每个目标最多一次。投射物按本帧起终点扫掠、选最早碰撞，不能因速度高穿过墙、地面或玩家；枪口在墙内时不能从墙后凭空发射。所有可碰撞造物统一阻挡与受损规则，兼容旧自由造物，不依赖遗漏的 role 字段。已经存在的箭矢相撞、近战击落箭矢等有效试打行为应保留，不能为新装备入口重置它们。

动作沿用现有角色骨架与动画系统，至少包括剑挥击、锤重击、弓蓄力／放箭、枪后坐及取墨。武器始终挂在手部握点，不重新扭曲各笔；攻击期间仍能移动、跳跃，不用静止全身贴图代替手部动作。受击、死亡、切装备和失焦中断持续动作。

## 6. 背包：物品与图纸

6／B 打开统一背包，分为“物品”和“图纸”两页。继续保留搜索、改名、收藏和六格快捷栏。物品是已经做好的装备；图纸是可重复制作的配方。

- 3 完成后自动入包并装备，不能要求先手动收藏才保存。每件有稳定物品 ID、类型、完整笔迹和握点。
- 换装备直接取出同一件，不耗墨、不复制物品。普通物件、武器和取墨器都可放快捷栏。
- 2/5 创建世界实体并记录图纸；3 同时记录可复用配方。建筑图纸用于摆放；装备物品用于立即装备，按钮文字必须区分。
- 从图纸重新制作是新物品／新世界实体，需要耗墨，不能用“复制图纸”绕过成本。复制图纸本身仅复制配方，不送实体。
- 建议物品 128 格、图纸沿用 128 张；初始取墨器不占普通容量且不能删除。相同配方重复制作可复用配方记录，不能每次装备挤满图纸页。
- 装备武器／工具时清掉旧建筑的待摆放状态，下一次点击不能放出之前的建筑。
- 初始附送取墨器，出生点附近有可达墨水池，零墨仍能补充。初始取墨器可再次取出，不因死亡丢失。

本阶段不加入掉落、交易、重量、磨损或弹匣管理。旧武器迁移成默认剑类装备并保留外形、握点；原图纸仍保留。旧 Q 试验弓若没有对应物品，不作为玩家正式持有装备迁移。

## 7. 墨水消耗

建议满值 **100**，初始满墨。HUD 小幅常驻显示墨水条和数值，低于 10 提醒但不遮挡绘画。

| 行为 | 建议消耗 |
| --- | --- |
| 画线 | 每米 0.05；一笔 2 米只用 0.1 |
| 射箭 | 成功发射每箭 0.05 |
| 开枪 | 成功发射每发 0.03 |
| 近战、拿出已有物品、移动、编辑、取墨 | 不耗墨 |

满墨可画约 2000 米，或独立射约 2000 箭／3333 发子弹。数值用于表达“很慢”，后续按真实游玩调节，不把反复补墨做成主要负担。

- 按新增线段的世界长度计费，抬笔、停顿、重复渲染和重采样不收费；不能按鼠标事件数或屏幕像素计费。
- 画的当下逐段扣墨，生成确认不重复扣。塑形按原草稿已付的线长结算，不因规整后的线长补扣。
- 墨水不足时只接收可支付的线段部分，并停止后续落墨；保留已有草稿，允许之后补墨接着画，绝不负数。
- 放箭／枪弹仅在成功生成时扣费；冷却、取消蓄力或投射物上限导致的失败不扣墨。持续开枪每发独立检查余额。
- 撤销已经画出的线条不退墨，重做同一条操作不再次扣墨；删除物体、复制配方不产墨。重新手动画线照常计费。
- 配方记录支付基准线长：3 由原手绘线长确定，2/5 同样记录原线长；旧配方没有记录时取合法几何路径总长。再次制作按该长度乘绘画费率一次扣费，失败不扣。装备图纸不重复收开火费用。
- 到零仍能移动、近战、使用已有造物和取墨器；新落墨与远程射击停止。未确认的付费草稿保存，否则退出会白白损失墨水。

墨水属于个人资源，不是共享池余额。两个人的绘画和射击分别扣各自的墨水。

## 8. 地形墨水池与取墨动作

出生区域放一个明确可达的池子，探索区域按地形固定点／种子布置更多池子，不随镜头漂移。池子具有轮廓、墨面微动、距离内提示；无须付费生成新素材。

建议首版池水可再生、不设共享枯竭，避免两人争抢导致无法创造。池子属于地形设施，暂不允许 4 删除或战斗摧毁，也不新加淹死等伤害。

玩家背包取出取墨器，1 持有，靠近池边约 1.5 米并站在可支撑表面、到取墨点没有实心地形／造物阻挡，按住使用开始补充。建议每秒 **25**，全空约 **4 秒**补满，按持续时间逐步入账；满墨自动结束，松手、走开、跳跃、受击或切换模式／装备会中断，已取到的保留。

动作循环：身体微俯 → 手和器具探向墨面 → 舀取／提起回收；同时有池面波纹、墨流和轻微声音。补满有短提示。该动作单独制作，不能复用挥剑动画。移动输入能立即打断动作，世界始终运行。

## 9. 保存与多人边界

- 个人资料增加墨水余额、物品列表、装备物品 ID、快捷栏引用及未确认草稿／阶段。类型为受限枚举，数字必须有限且在合法范围，握点必须仍在线条上。
- 单机读取恢复墨水、装备及草稿，但不恢复按住的输入、正在射击、蓄力或取墨循环。死亡保留物品和当前墨水，不通过死亡免费补满。
- 本机个人资料按变更延迟写入，正常退出立即保存；联机后墨水、装备与资源结算由服务器维护，本机缓存不决定余额，玩家不能通过换客户端／重连补满。图纸收藏继续个人保存；当前正式规范“重开房从图纸重新装备”需随本稿修改为恢复合法物品装备。
- 世界存档记录池子 ID、位置与生成种子；首版无限池不需要保存剩余量。旧作品加载补齐出生区域池子，保留原世界。
- 写入前验证完整候选存档，临时文件成功后原子替换并保留上一份；超大塑形等非法对象不能覆盖有效存档。v1/v2 迁移另存，保留旧文件。
- 墨水和背包物品不放进可整份回滚的世界快照；不能撤销收藏后复活被打坏的建筑，也不能用撤销恢复已耗墨水。
- 联机时新增物品、生成和发射各有操作编号；扣墨与生成一次提交，重复请求不重复收款／出物品。取墨按服务器时间、距离和工具状态结算，切工具或死亡立刻停止。
- 对方能看到手持类型、使用动作、箭弹与取墨；个人轮盘和背包只在本人界面。草稿按原 SPEC 同步展示。

## 10. 实施顺序与验收

先完成并验证旧存档保护、生成／编辑范围与碰撞校验、切装备残留摆放和战斗遮挡，再依次加入：1/3 流程 → 物品背包／迁移 → 类型攻击及人物动作 → 墨水池和取墨 → 联网权威结算。既有并行修改先读取合并，禁止整文件覆盖。

本机阶段至少验证：

1. 1 连续拖动不画线；2 保留任意原笔迹造物，5 的 44 种形状不回退。
2. 3 四次按键完整推进，多笔与握点外观不变；第三次只打开轮盘，第四次才装备和反馈。无点／无类型、满包、取消、失焦、触控和窄屏都有明确结果。
3. 六种物品可保存、切换、重新装备，建筑待摆放状态不会混入攻击。旧存档迁移不覆盖原件。
4. 剑、锤、弓、枪动作不同；弓蓄力取消不出箭，枪按冷却出弹；高速扫掠、侧向墙体遮挡和同次挥击去重正常。
5. 相同世界路径不同采样密度扣墨相同；生成不重复扣；重印付费；失败不扣额外费用；余额不足无免费箭弹、无负数。
6. 零墨拿初始取墨器能够恢复；池子遮挡、超距、跳跃和受击及时中断；动作可见，按实际取墨时间恢复。
7. 保存重开恢复付费草稿、类型、握点和墨水；无效写入保留上次好档；撤销不回墨、不复活被破坏物体。
8. 在隔离副本运行相关测试，桌面及窄屏真实渲染检查轮盘、武器、HUD 和取墨动作。仅文档审阅不算功能验收。

后续双客户端验收增加：个人扣墨隔离、重复命令、重连防补满、池子交互与动作同步、互伤遮挡和 Railway 异地实测；这些不能由单机截图代替。
